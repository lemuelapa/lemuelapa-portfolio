01 / MY CONTRIBUTION

The homeowner experience

A simple journey from a house photo to a colour preview.

Photo upload
Built the interface for visitors to upload a photograph of their house as the starting point for a personalised preview.
Coating colour selection
Built the colour-selection step so homeowners can choose the coating colours they want to visualise.
Generated preview
Connected the selected colours and uploaded photograph to the generation flow, then presented the resulting preview in the visualiser.
02 / MY CONTRIBUTION

Gemini API integration

Connecting the user interface to AI image generation.

Built from scratch
Personally built the visualiser from scratch, taking responsibility for the full-stack implementation of the upload, selection, and preview journey.
AI generation
Integrated the Gemini API to generate house-coating previews from the visitor’s photograph and colour choices.
End-to-end interaction
Connected the frontend journey with the AI processing integration so visitors can complete the experience in one tool.
03 / MY CONTRIBUTION

Usage limits & abuse safeguards

Controls designed to limit excessive use of the generation service.

Six-try limit
Implemented a limit of six tries per user to restrict repeated use of the visualiser.
Additional checks
Added IP-related checks and hashing as part of the abuse safeguards. These controls support the usage restriction and help reduce misuse.

Built lead capture into the visualiser experience so visitors can submit an enquiry to All Weather Coating.
