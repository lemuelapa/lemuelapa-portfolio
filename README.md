### Web Performance Analytics · [Dashboard](https://lemuelapa.github.io/web-performance-analytics/) · [Code](https://github.com/lemuelapa/web-performance-analytics)
**Role:** Data Analytics Case Study
**Stack:** Python (pandas, matplotlib), SQL (SQLite), HTML/JavaScript dashboard
How fast are websites built on WordPress vs other platforms? Using real Chrome user data from HTTP Archive, I found WordPress passes Core Web Vitals on 49% of sites, Elementor sites on 37% and WP Rocket sites on 53%, with loading speed (LCP) as the main bottleneck.

## About this site

A lightweight static site with no framework or build step, hosted on GitHub Pages.

| File | Purpose |
|---|---|
| `index.html` | Home page: hero, 13 project cards, about, expertise and contact form |
| `xo3d.html`, `awc-visualiser.html`, `awc-website.html`, `capitalixe.html` | Detailed case studies |
| `style.css` | Responsive charcoal-and-green design |
| `script.js` | Accessible project filters (All, Websites, Interactive & AI, Brand & product, Business Systems, Data Analytics) and the contact form |
| `images/` | Project previews and profile photo |
| `.nojekyll` | Serves the site as plain static files on GitHub Pages |

**Run locally:** open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
